# Code Mode research for the Recoup MCP cutover

Reviewed November 27, 2026. This evidence informs the proposed architecture. Vendor measurements describe their workloads. The rollout needs its own matched Recoup measurements before assigning savings or retiring a capability.

## Where the context goes

A connection can incur three different costs. The client downloads `tools/list` over the wire, the host decides which descriptions and schemas enter the model prompt, and later tool calls add inputs, intermediate results and final output. A smaller manifest guarantees fewer advertised tools. The tokenizer, client deferral, discovery depth and workflow determine the actual savings. A search result that returns an entire OpenAPI document can consume the tokens saved at startup.

Cloudflare's original experiment converted MCP definitions to TypeScript signatures, supplied them together, and ran model-authored programs in network-isolated workers with host callbacks. A dependent read could pass its result directly to the next call. Its subsequent public API server moved discovery behind `search` and used `execute` with an authenticated HTTP client. Cloudflare reports roughly 1,000 tokens for the interface over an API with more than 2,500 endpoints. Recoup can use the same discovery principle with a broker that resolves reviewed operation IDs. That lets the broker enforce account, resource, effect and response rules on every call. [Original Cloudflare experiment](https://blog.cloudflare.com/code-mode/) · [Cloudflare API MCP server](https://blog.cloudflare.com/code-mode-mcp/)

Anthropic describes a client-side alternative in which the agent browses generated tool modules, composes calls in code, and returns a projection. Its illustrated reduction from 150,000 to 2,000 tokens depends on that catalog and task. Its separate developer-platform work offers deferred search, programmatic tool calling and worked examples. Claude Code already defers most MCP definitions in supported configurations, initially loading tool names and server instructions. A fair baseline therefore exercises ordinary named Recoup tools with the host's usual deferral, including any existing single-call aggregate that solves the task. [MCP code execution](https://www.anthropic.com/research/code-execution-with-mcp) · [Advanced tool use](https://www.anthropic.com/research/advanced-tool-use) · [Programmatic tool calling](https://platform.claude.com/docs/en/agents-and-tools/tool-use/programmatic-tool-calling) · [Claude Code tool discovery](https://code.claude.com/docs/en/mcp#scale-with-mcp-tool-search)

## Execution choices

The guest program needs standard JavaScript control flow, JSON values and a narrow asynchronous host call. The trusted side owns the route, credentials, principal, method, resource checks and call ledger. Pin the guest language and limits separately from the catalog revision. Typed discovery can describe JavaScript in TypeScript declaration syntax without promising to compile arbitrary TypeScript projects.

| Approach | Advantages | Cost to qualify |
| --- | --- | --- |
| Per-run Cloudflare Dynamic Worker with one RPC binding | The platform can block network access while preserving specific service bindings. CPU and subrequest limits are configurable. The higher-level Code Mode SDK supplies discovery and execution records. | Per-run Vercel Sandbox microVM | Fits the API's current platform. Vercel supports an outbound firewall and credential brokering. It also offers a full OS if a future workflow requires one. [Vercel Sandbox](https://vercel.com/docs/sandbox) · [Sandbox firewall](https://vercel.com/docs/sandbox/concepts/firewall) | Default egress is open. Configure the sandbox before launch with a trusted broker channel as its only route to capabilities. Isolate each run's identity and bound the VM lifecycle, resources and outputs. Measure boot and RPC overhead for one small read as well as a composed task. A host-wide HTTP allowlist alone cannot enforce operation-level authority. |
| Embedded JavaScript engine via WASM, isolated from the credential-bearing service | Small guest API, portable deployment and explicit registered host functions. QuickJS offers runtime memory and stack limits and execution interrupts. Executor v1 demonstrates the host bridge. | Direct host-discovered named tools | Preserves current individual descriptions, native confirmations and simple calls. A host with deferral can already load a small fraction of a large catalog. [Claude Code discovery](https://code.claude.com/docs/en/mcp#scale-with-mcp-tool-search) | Performance and availability depend on the host. The interface exposes operations individually, and ordinary tool calls can send intermediates to the model. Retain as a measured baseline and rollback during migration. |

Choose the broker contract before choosing a runtime library. A runtime adapter should accept bounded source and data, expose only a broker callback and return a bounded value or classified error. The identical fixture suite must pass for a replacement adapter. A schema compiler, account platform or durable runtime can be evaluated independently on that boundary. Avoid coupling catalog admission, payment rules, actor identity or documentation ownership to an executor vendor.

## Tests derived from migration experience

1. **Search ordinary requests.** Compare a short query in a musician's own words, a synonym, an exact operation ID, an ambiguous request and a no-match request. Return ranked summaries before details. Limit bytes as well as rows. Exercise a stale discovery cursor after publishing a revised contract. Require earlier versions to fail explicitly or retain their documented compatibility.
2. **Qualify each behavior and consumer.** For every named operation and supported mode, compare old and candidate paths with the same actor and resource. Include denied access, missing data, full pagination, precision, expected media, status and errors. Give aggregate operations equal opportunity. For writes, prepare a seeded disposable object, obtain real confirmation, read back the effect independently and exercise cleanup. Record unknown consumers and keep their compatibility path until an owner determines disposition.
3. **Test recovery at the effect boundary.** Exercise duplicate requests, mismatched content under one key, lost acknowledgments, expiry, revocation and cancellation before and after dispatch. Serialize effectful calls across approval points. Return explicit partial results and reconcile uncertain writes against the original operation. Model responses, cached local results and successful transport responses alone cannot establish an external outcome. Cloudflare's own replay API flags ordering considerations for concurrent calls around pauses. [Replay mechanics](https://developers.cloudflare.com/agents/tools/codemode/api-reference/)
4. **Measure total cost per correct answer.** Use identical identities, fixtures, requested outputs, model versions and cache state for named and code-mode paths. Pin host versions and run both eager and deferred clients. Separate initial wire bytes, actual or explicitly estimated prompt tokens, discovery tokens, tool-result tokens, total turns, API calls, human approvals, wall time and cost. Report median, tail latency and failures by workflow. Include a single lookup, a paged read, a dependent join, a private artifact, a bounded write and an interrupted long job. Preserve failed cases in the report and prioritize correctness and authorization over token reduction.
5. **Exercise installed hosts.** Test fresh connect, expired credentials, reconnect, changed capabilities, valid reviewer sign-in and the actual confirmation UI in each release target. A passing server test, deployment or cached host descriptor supports a different claim from a successful user journey. Record precise versions, observed behavior and retained rollback evidence alongside each admission.
